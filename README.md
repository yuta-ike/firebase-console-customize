# Firebase Console Background

## 概要

Firebase Console で本番環境・ステージング環境・開発環境をわかりやすくするために、Firebase Console の Web ページの背景色を自由に変更できる Chrome 拡張機能です。

## 機能

### 管理画面

管理画面で、Firebase の Project ID と背景色の組み合わせを設定できます。

### 色の変更機能

Firebase Console の Web ページを開くと、設定した背景色に変更されます。
